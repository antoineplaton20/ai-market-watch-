# Catalogue V15

Le catalogue initial est généré par `bot_factory.catalogue` et exporté dans `catalogue/bots_v15.json`.

Familles initiales: Intelligence, Research, Data, Software, QA, Security, Orchestration, Tools, Memory, Evaluation, Product, Infra.

Chaque famille possède plusieurs spécialistes. Le catalogue est volontairement extensible: un même modèle de fiche peut générer des variantes par domaine sans copier-coller de logique.
